Problem Statement:
Traditional offline booking methods present several challenges that a computerized system can effectively solve.
Slow and Inefficient-
The process of manually checking availability and recording bookings is time-consuming for both customers and staff.
No Real-Time Availability-
Customers have no way of knowing the current seat status without direct communication, leading to uncertainty and potential overbooking.
Prone to Manual Errors-
Handwritten logs or basic spreadsheets can easily lead to mistakes in bookings, names, or payment details.
The Need for Automation-
A simple, computerized system built in C can automate these tasks, providing speed, accuracy, and reliability.



Project Objectives
The primary goal is to develop a robust and user-friendly Bus Reservation System. The key objectives for this project were:
Implement a complete Bus Reservation System using C.
Incorporate a secure login authentication for users.
Enable functionality to book and cancel tickets seamlessly.
Display a real-time seat map and status.
